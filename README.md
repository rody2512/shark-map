# 🦈 Shark Map
### Exploring Shark Locations and Marine Ecosystems

**Shark Map** is an interactive web-based visualization project developed as part of the **NASA Space Apps Challenge**.

The project combines a 3D visualization of Earth with an interactive geographical map to explore shark locations and visualize plankton distribution, helping users better understand marine ecosystems.

## 🌍 Project Overview

Shark Map provides an interactive experience that allows users to explore the Earth, navigate to different geographical locations, and visualize shark sightings and plankton concentration data.

By combining geographical visualization with data representation, the project aims to make marine ecosystem information more accessible and engaging.

## ✨ Key Features

- **3D Earth Visualization:** Explore a rotating 3D model of Earth with a space background and cloud layers.
- **Interactive Navigation:** Zoom in on the globe and transition to a geographical map.
- **Shark Tracking:** Visualize shark locations using interactive map markers.
- **Shark Selection:** Select a shark from a dropdown menu to locate it on the map.
- **Multiple Map Views:** Switch between Streets, Satellite, and Hybrid views.
- **Plankton Visualization:** Display plankton distribution across geographical locations.
- **Data Visualization:** Present plankton concentration using interactive bar charts.
- **Interactive Charts:** Click chart data points to navigate to their corresponding locations on the map.

## 🚀 Getting Started

### Prerequisites
- A modern web browser.
- Visual Studio Code (recommended).
- Live Server extension or another local development server.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/rody2512/shark-map.git
```

2. Navigate to the project directory:

```bash
cd shark-map
```

3. Open the project folder in Visual Studio Code.

4. Run `index.html` using Live Server.

5. Explore the 3D Earth and interact with the map.
